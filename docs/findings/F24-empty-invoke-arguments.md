## Minimal counterexample and exact behavior

Original [internal_call source](../../lowering/defs/bytecode/python-o1-no-asm-opt-sources/internal_call.vy):
`foo()` calls no-argument `bar()` returning7. Source succeeds with7;
lowering emits **INVOKE [Label bar]**, no extra argument operand, with a stack
return. Old `setup_callee` rejected `NULL args`, so raw Venom returned
`Error "invoke: empty function"`. Generated bytes were not thereby wrong;
the mismatch was in the Venom model's entry rule.

Current setup rejects **only** a function with no blocks. A nonempty function
with empty params gets `vs_return_pc_token=0w`; nonempty argument vector gets
`LAST args`. No synthetic user parameter is inserted. Exact permanent witness:

```text
bar block:
  instruction 0 RETPC_PARAM [Lit 0w] ["pc"]
  instruction 1 RET [Lit 7w; Var "pc"] []
caller:
  instruction 2 INVOKE [Label "bar"] ["answer"]
```

`step_inst 1 zero_args_context caller s = OK (update_var "answer" 7w s)` for
arbitrary s: other caller fields are preserved. For `mk_raw_function "bar" []`,
INVOKE still returns `Error "invoke: empty function"`, even with fuel/args
arbitrary. The full callee-record theorem checks empty params and every
inherited memory/account/oracle/frame field, not merely successful lookup.

## Shape/pipeline boundary, token and FMP are distinct

TASK043, landed`414b2da6`, supplied [unitShapeDefs](../../venom/compiler/unitShapeDefsScript.sml)
and [literal shape checks](../../venom/compiler/unitShapeChecksScript.sml):
`unit_shape_ok`, `o1_source_unit_ok`, `opaque_use_ok`, proved L4
`entry_fn_first_lookup`. Public entry is first, no entry parameter prefix or RET;
non-entry functions exclude STOP/RETURN; RETPC-derived variables are only opaque
last/unique RET operands. Empty user args do not bypass these unit contracts.

The source token0 is **not** a concrete assembly return address. Frame-aware
[function interfaces](../../venom/codegen/venomToAsmPropsScript.sml) keep that
distinction; [current entry](../../lowering/e2e/e2eEntryScript.sml) and
[codegen initial relation](../../venom/codegen/codegenCorrectnessScript.sml)
retain frame/FMP obligations. TASK061 requires equality of all four remap fields
including return token and three FMP fields; its frozen GETFMP counterexample
is linked in [F21](F21-fixed-memory-and-names.md). This does not prove arbitrary
INVOKE/FMP preservation without the other premises.

Shape tests are not S2/S6 producer proofs: [raw lowering stages](../../lowering/vyperLoweringCorrectScript.sml)
and [executed O1 stages](../../venom/compiler/o1PipelineCorrectScript.sml) remain
admitted; S4 is forward unit simulation, not every old pass's lift_result.

# Selected entry proof reference

These patches preserve proof attempts for adapting arbitrary-calldata entry proofs to current suppliers. They are reference material, outside every theory build, and must not be applied as a source intake.

`selected-entry-suppliers.patch` contains the 63 absent supplier files from commit `3f3ab9111caa29721ecf9195bd8c527c1e6f039f`, relative to `5ff3d9f51c067f0c1d4ed5e989104d8bb6be1a75`. Shared source files are excluded. The donor depends on different compiler and proof definitions; successful checks there do not establish compatibility with another base. Its newer suppliers contain four theorem statements with local bindings, an unused local theorem, and no CI-root reach. Those hygiene failures remain unresolved in this archive. The two child-relation definitions are proof proposals without a separate shared-interface approval.

`selected-entry-assembly.patch` preserves the unfinished endpoint attempt relative to that donor commit. Its final assembly uses `FAIL_TAC`; the selected endpoint and the full dispatched correctness theorem remain unproved.

Keep current executable definitions, existing supplier owners and theorem contracts when adapting an argument. Retired source owners in this archive are historical context.

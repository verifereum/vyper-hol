# Conditional occurrence-to-ctx_sim assembly audit

Scope: C3.6.41. The conditional theorem in dftOccurrenceCtxSimScript.sml is checked; this audit does not assert its premises follow from the frozen task.

## Native consumer

`dft_occ_terminal_transport_ctx_sim` consumes valid source and target entry lookups, source native Halt/Abort classification, sparse numeric oracles for both initial reading lists, uniform prefix compatibility for both occurrence starts, and forward cleared-terminal transport with exact result or same Abort code. Its conclusion is actual `ctx_sim D C C' s s'`. Target fuel is existential in ctx_sim_def (o1PassContractScript.sml:239); no same-fuel theorem is needed here.

Extraction: `dft_occ_terminal_extract` (dftOccurrenceTerminalScript.sml:156) takes a source native Halt/Abort run and uniform prefix compatibility, and returns a cleared occurrence terminal plus materialized native-result equality. Realization: `dft_occ_terminal_realize` (same source:136) needs target compatibility at only the selected terminal index and a Halt/Abort result, yielding some native fuel. `dft_materialized_mixed_terminal_dead_result_rel` accepts unequal counters and equal-code Abort with unequal states. These three interfaces now compose in the checked conditional consumer.

## Premise producers and gaps

* Valid entries: the conditional consumer assumes the six concrete lookup/entry equations. The frozen theorem instead gives LIST_REL function correspondence and equal ctx_entry. Alignment of first-match lookup and entry labels along all edits must be supplied by the positional structural APIs; this consumer does not do that assembly. `dft_occ_start_def` initializes prev_bb=NONE, current_bb=lbl, inst_idx=0, zero count and empty stack, exposing the root expected by orbit APIs.
* Missing/invalid entries: NONE ctx_entry, failed function lookup, or NONE fn_entry_label return Error by run_context_def/run_function_def. Therefore source ctx_sim is vacuous in those branches. They must be split off before applying this valid-entry consumer, while separately preserving the frozen lowered-invariant conclusion. No target termination is required when the source cannot terminate.
* Native source classification: valid entry alone does NOT suffice (E0344). terminates_def accepts IntRet and excludes only Error. `dft_run_blocks_not_ok` excludes OK, not IntRet. The frozen `o1_ctx_shape` DOES contain a relevant structural restriction: o1_fn_shape_def:434-435 requires entry_fn_no_return for a function whose name equals ctx_entry. entry_fn_no_return_def:340-342 excludes RET, RETFMP, DRET throughout fn_insts. `entry_fn_no_return_no_ret` only converts this structural predicate to entry_fn_no_ret; it is not a semantic native-result classification theorem. Thus root IntRet appears structurally excluded under the frozen hypotheses, but a checked semantic producer for the explicit classification premise is still missing in this bounded audit. It must account for recursive INVOKE results rather than assume they propagate as root IntRet. No counterexample to the frozen theorem is claimed.
* Numeric oracles: dft_sparse_oracle_def is precisely the list lookup followed by zero. `dft_allocated_oracle_exists` in dftSparseOracle requires an injective partial read allocation p and then produces a finite ys for dft_allocated_value p xs. This is a conditional finiteness theorem, not an occurrence-address allocation producer. The source reading list must be chosen once before quantifying over prefixes/fuel, and must yield gas_variant with the fixed target state. An actual uniform allocation/finite-support producer remains missing.
* Uniform prefix compatibility: dft_occ_prefix_compatible_def and dft_occ_prefix_compatible_iff provide the local address-value/numeric replay interface; `dft_occ_prefix_replay` uses it, not produces it globally. Local event set coverage, singleton unmatched support, and cofinal cuts are not sufficient to produce a uniform finite numeric oracle. Temporal occurrence uniqueness and allocation for all events, including discarded/pending GAS, remain to be assembled.
* Terminal-forward transport: dftRootedOrbitTerminal supplies exact GAS/GAS transport and exact-or-same-code mixed transport in both directions, conditional on their cuts. Ordinary/INVOKE and pending GAS/INVOKE transports and edit orientations must still be composed across the actual full positional edit sequence, retaining original-root readiness and a coherent oracle. These local theorems do not supply a global C-to-C' terminal hypothesis on their own. No all-edit producer is asserted here.
* Memory: ctx_sim covers terminal observations only. The frozen implication concerning o1_lowered_inv additionally requires raw memory-range coverage, including divergent runs. `dft_raw_occ_adequacy` (dftOccurrenceReplayScript.sml:182) converts native raw_reachable to occurrence observations under distinct block labels and uniform numeric compatibility. `dft_occ_observation_raw` (same:166) converts an occurrence fetch back to native raw reachability under prefix compatibility. dftRootedMixedCoverage and dftRootedGasOrbit give bidirectional local memory/range transport, conditional on cuts. These must be composed across all edits and materialization, then consumed via mem_inv_raw_reachable. Terminal transport is no substitute. ctx_eom_bounded separately needs fn'=dft_fn fn preservation, as required by the frozen theorem.

## Disposition

The native terminal consumer is available only conditionally. Remaining substantive boundaries are uniform finite allocation/compatibility, all-edit composition with roots and orientations, source external-terminal classification from actual shape, and raw-memory-range assembly. None is discharged by the consumer or this audit. Existing accepted local APIs and frozen statements remain unchanged.
